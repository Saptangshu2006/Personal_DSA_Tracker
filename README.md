# 🚀 Custom DSA Mastery Tracker

A self-paced, zero-distraction Data Structures & Algorithms (DSA) tracking web application. Built specifically to help prepare for **Service-Based Companies (TCS, Infosys, Cognizant, Wipro, Accenture)**, mid-tier product companies, and early-stage tech startups.

**Live Application:** [https://saptangshu2006.github.io/Personal_DSA_Tracker/](https://saptangshu2006.github.io/Personal_DSA_Tracker/)

✨ Key Features
⏱️ No Time Limits / Fully Self-Paced: Removed the strict 60-day deadline structure. Track your progress module-by-module at your own speed.

🎯 100% DSA Focused: Removed non-coding elements (AI topics, aptitude, general theory) to focus purely on core algorithms and data structures.

📚 190+ Curated Problems:

175 Original LeetCode/GFG Problems: Covering Arrays, Strings, Two Pointers, Stacks, Queues, Linked Lists, Trees, and Recursion.

18 High-Frequency LeetCode Additions: Expanded coverage for Grid BFS/DFS, 2D Dynamic Programming, Sliding Window variants, Heaps, and Monotonic Stacks to clear high-tier rounds (like Infosys SP & TCS Prime).

🎥 Integrated YouTube Video Links: Direct access to concept explanation videos for every topic.

💾 Local Persistence & Sync:

Automatically saves your checked state (localStorage) in your browser.

Includes Import/Export JSON Backup functionality to sync progress across different devices.

📊 Live Progress Stats: Real-time percentage counter for completed videos and solved problems.

📁 Topic Breakdown
Arrays, Strings & Basic Math (Loop logic, manipulation, prefix sum)

Two Pointers & Sliding Window (Optimized array searches & dynamic subarrays)

Hashing & Frequency Maps (O(1) lookups and string counting)

Recursion & Backtracking (Subsets, combinations, permutation logic)

Searching & Sorting (Binary Search variants & sorting algorithms)

Stacks & Queues (Monotonic stacks, queue traversals)

Linked Lists (Pointer manipulation, reversal, cycle detection)

Binary Trees & BST (Traversals, depth calculations, BST properties)

Graphs & Grid Traversal (Added) (BFS, DFS, Matrix Islands, Topological Sort)

Dynamic Programming (Added 2D variants) (Knapsack variants, LCS, Grid paths)

Heaps & Priority Queues (Added) (Top-K elements, frequency sorting)

🛠️ How to Use
Clone or Download:

Bash
git clone [https://github.com/your-username/dsa-mastery-tracker.git](https://github.com/your-username/dsa-mastery-tracker.git)
cd dsa-mastery-tracker
Launch:

Open index.html in any web browser. No server setup, Node.js, or npm install required!

Tracking Progress:

Click checkboxes on videos and problems as you complete them.

Your progress updates automatically and persists on page refresh.

Backing Up Progress:

Scroll to the footer and click Export Backup Code to copy your raw JSON state.

Paste it on another browser/device using Import Backup Code to keep your checklist synchronized.
